# Kilometerregistratie

Webpagina om elke maand de kilometerregistratie voor de reiskostenvergoeding in te vullen.

**Openen: <https://haasje33.github.io/heldr-kilometers/>** (pc en telefoon)

- De eerste keer vul je je naam en postcode thuis in.
- Zet per dag de plekken waar je naartoe ging in volgorde: werklocaties en huisbezoeken.
- De kilometers worden berekend via de snelste autoroute; controleer ze en download het Excel-bestand.

Wat je invult blijft alleen in de browser van je eigen apparaat bewaard en wordt niet naar deze website
gestuurd. Alleen de postcodes van een rit gaan naar de routedienst (PDOK en OpenStreetMap) om de afstand
te berekenen.

Deze repository bevat alleen de gepubliceerde pagina (`index.html`); de broncode en tests staan elders.
